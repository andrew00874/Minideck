# MiniDeck

[English](README.md) · **한국어**

**다운로드:** [한국어판 ZIP](https://github.com/andrew00874/Minideck/releases/download/v0.1.0-beta.1/MiniDeck-0.1.0-beta.1-win-ko.zip) · [영문판 ZIP](https://github.com/andrew00874/Minideck/releases/download/v0.1.0-beta.1/MiniDeck-0.1.0-beta.1-win-en.zip) · [베타 릴리스](https://github.com/andrew00874/Minideck/releases/tag/v0.1.0-beta.1)

Windows 10/11과 .NET Framework 4.8 이상이 필요합니다. 한국어판(`win-ko.zip`) 또는 영문판(`win-en.zip`) 전체를 풀고 `MiniDeck.exe`를 실행하세요. 두 버전은 같은 사용자 설정을 공유하며 동시에 실행하지 않습니다. 이 배포는 서명되지 않은 베타 버전입니다.

## 웹사이트 기존 탭으로 전환

웹사이트는 Chrome의 MiniDeck Browser Link 확장으로 연결합니다. `browser-extension/README.md`의 최초 설치 후, 같은 사이트 탭이 있으면 기존 화면을 유지한 채 전환하고 없을 때만 새 탭을 엽니다. 연결이 없거나 실패하면 안내만 표시하며 중복 탭을 열지 않습니다. 설치 앱 실행 방식은 그대로입니다.

## 온보드 매핑 저장

설정창 오른쪽 위 `키보드 온보드 설정`에서 키 1~3, 노브 좌회전·누르기·우회전의 출력을 편집합니다.
1. 연결된 1189:8890 키보드와 Report ID 3 형식을 자동 확인합니다. 여러 대면 대상 한 대만 연결하세요.
2. 저장할 레이어(1~3)를 선택하고 키/조합키 또는 미디어 기능을 지정합니다.
3. `초안 저장`은 PC 파일만 저장합니다. `전송 내용 보기`도 장치에 쓰지 않습니다.
4. `온보드에 저장`은 화면의 6개 매핑과 플래시 저장 명령을 장치로 전송합니다. 선택한 레이어의 기존 매핑을 덮어씁니다.
5. 저장 명령 전송 후 USB를 분리·재연결해 실제 동작을 확인하세요. 펌웨어 설정 재조회 명령은 확인되지 않아 자동 읽기 검증은 하지 않습니다.

화면 초기값은 장치에서 읽은 값이 아니라 저장된 PC 초안 또는 MiniDeck 연동 기본값입니다. 기존 장치 매핑의 자동 백업/복원은 지원하지 않습니다.
키보드 기능은 장치 내부에 저장되지만 앱 경로·아이콘·오버레이 설정은 PC에 남습니다.
MiniDeck 앱 실행/다이얼에는 `MiniDeck 연동값` 프리셋을 사용하세요. 다른 키/미디어 기능을 저장하면 그 키 입력을 내보내며 런처 동작을 자동 변경하지 않습니다. 전용 네이티브 이벤트 모드나 펌웨어 교체 기능은 아닙니다.
초안은 `%APPDATA%\MiniDeck\onboard-draft.json`, 전송 기록은 같은 폴더의 `onboard-*.log`입니다. 이 기록은 장치에서 읽은 백업이 아닙니다.
이 구현은 제공된 MINI KeyBoard.exe의 Report ID 3 쓰기 형식을 따릅니다. 자동으로 다른 프로토콜을 시험하거나 LED 설정을 변경하지 않습니다.

## 아이콘 커스터마이징

앱 선택 → `앱 / 아이콘 수정` → `PNG / SVG 선택` → 미리보기 확인 → `저장`.
`기본 아이콘` 버튼으로 원래 아이콘으로 되돌릴 수 있습니다. 새 앱을 추가할 때도 지정할 수 있습니다.
PNG와 자체 리소스로 구성된 SVG를 지원합니다(최대 4MB, PNG 최대 4096px).
투명도와 원래 비율을 유지하며 SVG는 256px PNG로 렌더링해 사용합니다. 외부 파일·인터넷 리소스를 참조하는 SVG는 지원하지 않습니다.
가져온 아이콘은 `%APPDATA%\MiniDeck\icons`에 보관하므로 원본 파일을 옮겨도 유지됩니다.
예제 벡터 아이콘은 `sample-icons/orbit.svg`입니다.
이 버전은 .NET Framework 4.8 이상을 사용합니다. 다른 PC로 복사할 때 EXE 옆의 DLL 파일과 `fonts` 폴더도 함께 복사하세요.

3키 + 누르기 지원 노브를 위한 Windows 런처 초기 버전입니다.
기존 MINI KeyBoard 프로그램은 배포에 포함하지 않습니다. 장치 설정은 `온보드에 저장`을 눌렀을 때만 변경됩니다.

## 시작

1. `MiniDeck.exe`를 실행합니다. 별도 설치나 관리자 권한은 필요하지 않습니다.
2. 기본 목록은 Codex, 탐색기, 메모장, 계산기입니다. Codex는 이 PC에 설치된 Windows 앱 ID를 사용합니다.
3. `앱 추가`로 실행 파일(.exe), 바로가기(.lnk), 폴더, URL을 등록합니다. 실행 인수는 별도 칸에 입력합니다.
4. 아래 세 개의 선택 상자에서 키별 앱을 고릅니다. 변경은 자동 저장됩니다.
5. 화면의 회전/누르기 버튼 또는 다음 단축키로 시험합니다.

| 조작 | 단축키 |
| --- | --- |
| 키 1 / 2 / 3 | Ctrl + Alt + Shift + F1 / F2 / F3 |
| 노브 왼쪽 / 오른쪽 | Ctrl + Alt + Shift + F4 / F5 |
| 노브 누르기 | Ctrl + Alt + Shift + F6 |
| 오버레이 닫기 | Esc 또는 약 4.5초 미조작 |

키보드를 연결한 뒤 기존 설정 프로그램에서 위 6개 입력을 각각 지정하여 장치에 저장하세요.
노브는 회전 한 칸당 조합키를 누르고 떼는 형태로 설정해야 합니다.
오버레이가 닫혀 있을 때 누르기는 목록을 열고, 열려 있을 때 누르기는 선택한 앱을 실행합니다.
원형 다이얼에 앱 아이콘을 배치하고 선택한 아이콘을 애니메이션으로 확대합니다.
가운데 원이나 앱 아이콘을 마우스로 클릭해도 실행됩니다.
다이얼은 밝은 반투명 유리 스타일이며 기본 지름은 360px입니다. 픽셀별 알파와 2배 해상도 렌더링으로 곡선 가장자리와 광택 테두리를 부드럽게 표시합니다. 설정창의 `다이얼 크기` 슬라이더로 280~560px 사이에서 조절하고 자동 저장합니다.
앱 이름은 다이얼 아래 작은 캡슐에 가운데 정렬합니다. 캡슐 폭은 이름에 맞춰 늘어나며 다이얼 폭의 78%를 넘지 않습니다. 긴 이름은 생략 없이 줄바꿈합니다. 아주 긴 이름은 이름 영역에서 휠로 스크롤하거나 위/아래쪽을 클릭해 이동할 수 있고, 마우스를 이름 위에 두면 자동 닫힘이 잠시 멈춥니다.
처음에는 마우스가 있는 모니터 오른쪽에 표시됩니다.
다이얼 어디든 왼쪽 버튼으로 잡고 드래그하면 이동합니다. 드래그는 앱을 실행하지 않으며 이동 중에는 자동 닫힘이 멈춥니다.
놓은 위치는 자동 저장되어 다시 열거나 프로그램을 재시작해도 유지됩니다. 모니터 분리 등으로 위치가 화면 밖이 되면 보이는 영역으로 보정합니다.
앱이 8개를 넘으면 회전 시 다음 묶음으로 넘어갑니다.

## 실행과 종료

- 닫기(X)는 트레이로 숨깁니다. 트레이 아이콘을 두 번 클릭하면 설정이 열립니다.
- 완전히 끝내려면 트레이 메뉴의 `종료`를 선택합니다.
- 자동 시작은 기본적으로 꺼져 있습니다. 설정에서 직접 켤 수 있습니다.
- 자동 시작을 켠 뒤 실행 파일을 옮겼다면 새 위치에서 옵션을 껐다 켜세요.
- 삭제 전 자동 시작을 해제하고 종료한 뒤 MiniDeck 폴더를 삭제하세요.
- 설정은 `%APPDATA%\MiniDeck\settings.json`에 저장됩니다. 직전 저장본은 `.bak`입니다.

## 현재 범위

- 온보드 설정에서는 지원 장치를 식별합니다. 런처 입력의 장치별 필터링은 아직 구현하지 않았습니다.
- 현재는 모든 키보드에서 해당 단축키에 반응합니다. 다른 앱이 먼저 점유한 단축키는 설정창 아래에 실패로 표시됩니다.
- 절대 경로 EXE이고 실행 인수가 없는 항목은 같은 경로의 실행 중인 창을 우선 활성화합니다. Windows의 포커스 제한이나 앱 구조에 따라 새 실행 요청으로 넘어갈 수 있습니다.
- Codex 같은 패키지 앱과 바로가기는 운영체제와 해당 앱의 실행 정책에 따릅니다. 웹 URL은 별도 Chrome 확장 설치 후 같은 origin의 기존 탭으로 전환합니다. 다른 프로필·시크릿 탭·다른 서브도메인은 재사용하지 않습니다.
- 브라우저 연동은 로직/연결 테스트와 별개로 확장을 실제 설치한 Chrome에서 추가 검증이 필요합니다. 온보드 저장의 분리·재연결 유지 여부도 사용자 기기로 확인해야 합니다.
- 관리자 권한 앱이 앞에 있을 때의 동작, 혼합 DPI 모니터, 실제 노브 입력은 추가 검증이 필요합니다.
- 설정창의 찾기에서 Codex의 내부 `codex.exe`를 고르지 마세요. 그 파일은 데스크톱 UI 실행 파일이 아닙니다. 기본 Codex 항목은 확인한 패키지 앱 ID로 열립니다.

## 빌드와 점검

Windows .NET Framework C# 컴파일러를 사용합니다.

```powershell
.\build.ps1
.\build.ps1 -Language en -OutputDirectory .\artifacts\en
.\scripts\package.ps1
.\MiniDeck.exe --self-test C:\absolute\output-folder
.\MiniDeck.exe --preview C:\absolute\output-folder
```

점검 시 이미 실행 중인 MiniDeck은 먼저 종료하세요. 출력 폴더는 미리 있어야 합니다.
자체 테스트는 별도 `test-data`에 설정을 저장하며 사용자 설정을 바꾸지 않습니다.
미리보기는 샘플 앱을 사용하며, 배포용 스크린샷에 사용자 설정을 포함하지 않습니다. 패키징은 `dist`에 한국어/영어 ZIP과 SHA-256 목록을 생성합니다. 의존성은 고정 버전과 해시로 복원하며 개인정보·제조사 프로그램·분석 파일은 포함하지 않습니다.
테스트는 단축키 등록, 메시지 처리, 앱 순서/삭제 시 할당 유지, 저장/복원, 오버레이 닫힘을 검증합니다.
실물 장치 입력이나 외부 앱 실행 성공을 검증하는 테스트는 아닙니다.
