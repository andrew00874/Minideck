# MiniDeck Browser Link

Chrome에서 최초 한 번만 설치합니다.

1. `setup.ps1` 실행 (현재 Windows 사용자에게 로컬 연결 호스트 등록).
2. Chrome 주소창에 `chrome://extensions` 입력.
3. 오른쪽 위 **개발자 모드** 켜기.
4. **압축해제된 확장 프로그램을 로드합니다** → 이 `browser-extension` 폴더 선택.
5. MiniDeck 다이얼에서 웹사이트 선택.

확장 ID: `mecekhgbdppcabapefkdljicahcnibcf`

같은 origin(프로토콜·호스트·포트)의 일반 탭 중 마지막 사용 탭을 활성화합니다. 페이지 경로·쿼리·해시는 바꾸지 않으며, 새로고침하지 않습니다. 탭이 없으면 새로 엽니다. 최소화된 창도 복원합니다. 시크릿 탭은 대상에서 제외합니다. 서로 다른 서브도메인은 별도 사이트입니다.

사이트를 사용하는 Chrome 프로필 한 곳에만 설치하세요. 다른 프로필·브라우저의 탭은 검색하지 않습니다. `tabs`, `nativeMessaging`, `alarms`, `storage`, `scripting` 권한을 사용합니다. 사이트 접근은 `https://translate.google.com/*`와 `https://papago.naver.com/*`로 제한하며 엔진 확정 후 원문 입력칸에 글을 쓰고 전체 원문이 입력됐는지 확인합니다. 다른 페이지 본문·쿠키·비밀번호는 수집하지 않습니다. 탭 URL 목록은 확장 안에서만 처리하고 MiniDeck에는 처리 결과만 반환합니다.

1.2.0부터 Google 번역·파파고는 원문을 이동 주소에 넣지 않고 입력칸에 직접 전달합니다. 검색은 결과 주소를 사용합니다. 엔진별 전용 결과 탭을 갱신하고 일반 웹사이트 항목은 기존 페이지를 유지합니다. Google 번역은 5,000자, 현재 파파고는 3,000자 한도를 넘으면 탭을 열기 전에 거부합니다. 세션 저장소에는 탭 ID와 origin만 두며 원문·검색어는 저장하지 않습니다. Chrome 또는 확장을 다시 시작하면 추적 정보가 초기화됩니다. 확정한 글은 해당 서비스에 전달되고, 검색 주소나 번역 서비스가 자체적으로 갱신한 주소는 브라우저 방문 기록에 남을 수 있습니다.

1.2.0으로 업데이트할 때는 MiniDeck 실행 파일 두 개와 이 폴더를 교체한 뒤 `chrome://extensions`에서 MiniDeck 확장의 **새로고침**을 누르세요. 먼저 원문 없는 기능 확인 요청을 보내므로 이전 확장에는 번역할 글을 전달하지 않습니다.

브라우저를 닫았거나 확장이 연결되지 않았으면 MiniDeck에 안내가 나타납니다. 이때 기존 URL 실행으로 우회하지 않아 중복 탭을 만들지 않습니다. 연결 복구는 확장 아이콘 클릭 또는 최대 30초 후 자동 재시도로 가능합니다.

삭제: Chrome에서 확장을 제거하고 `HKCU\Software\Google\Chrome\NativeMessagingHosts\com.minideck.browser` 레지스트리 키를 제거하면 됩니다. 폴더를 이동했다면 setup.ps1을 다시 실행해야 합니다.

2026-10-01 Windows/Chrome의 설치된 확장에서 Google 번역 5,000자·파파고 3,000자를 직접 전달했습니다. 유니코드·빈 줄·끝 줄바꿈이 포함된 전체 원문 일치와 번역 결과 표시, 같은 결과 탭 재사용을 확인했습니다. 이 검증은 물리 키보드나 모든 선택 영역 원본 앱의 호환성 검증을 포함하지 않습니다.

검증: `node test.cjs`. 브라우저 실제 통합 검증은 확장 설치 후 수행합니다.
